# HEXA 유기화학

분자를 직접 조립하며 **어떤 물질이 되고 IUPAC 이름이 어떻게 바뀌는지**, 그리고 시약을 넣으면 **무엇이 생기는지** 한 단계씩 보여 주는 유기화학 공부 앱입니다.

- 사이트: https://dhsrua555.github.io/organic-chem/
- 디자인: 짙은 남색 + 전기 파랑, 육각형 기하. 와이어프레임 3D 분자가 바뀔 때 가로 줄무늬로 풀렸다 맺힙니다 (orano.group 인터랙티브 슬라이더의 분위기를 참고, 자산은 옮기지 않음).
- 커서 효과 (igloo.inc 의 반응하는 화면을 참고): 커서를 느리게 따라오는 육각 조준선, 누른 자리에서 퍼지는 육각 물결, 3D 분자의 원자가 커서를 피해 밀려나며 빛나고 원자 이름표가 뜸, 바닥 격자에 커서 빛 · 물결. 길게 누르면 분자가 분해도처럼 벌어짐. 움직임 줄이기 설정에서는 꺼짐.
- 골라 보기: 한 화면에 다 펼치지 않고 탭으로 하나씩 — 구조식 편집기는 이름 카드만 늘 보이고 ‘명명 변화 · 명명 과정 · 입체화학 · 참고 사항 · 비교’ 를, 반응 예측은 반응식만 늘 보이고 ‘반응 메커니즘 · 선택성 · 입체화학 · 최근 연구’ 를, 명명법은 절(명명 절차는 한 단계씩, 이전 · 다음)을, 작용기 페이지는 ‘예제 화합물 · 위치별 치환체’ 를 고릅니다. 고른 탭은 기억합니다. 조각 팔레트도 무리별 탭, 시작 분자 목록은 접을 수 있음.
- 버그 제보함: 아래 막대의 ‘제보’ → 종류 · 내용을 적으면 지금 페이지 · 분자 SMILES · 이름 · 반응 결과 · 브라우저 · 최근 오류를 붙여 구글 폼으로 바로 보냄(로그인 필요 없음, 응답은 구글 시트에 쌓임). GitHub 이슈 · 복사 · (claude.ai 에서는) 페이지 댓글로도. 쓰던 글은 브라우저에 남음. 폼은 `dev/bug_form.gs` 를 script.google.com 에서 한 번 돌려 만들었고, 나온 ‘▶ HEXA’ 주소가 `js/report.js` 의 `FORM_URL` (비우면 GitHub 이 먼저). GitHub Pages 에서는 페이지 안에서 바로 제출, claude.ai 에서는 채워 둔 폼을 새 창으로. 시험: `python dev/bugform_test.py` (구글 요청을 가로채 확인), `--live` 는 실제 폼으로 [시험] 제보 하나
- 키캡 버튼: 고르는 버튼은 키보드 숫자 키처럼 솟아 있다가 누르면 들어가고, 골라 둔 키는 파랗게 눌린 채 (css 끝의 ‘키캡’ 블록).
- 용어: 화면의 이름 · 해설은 대한화학회 · 대학 교재 용어로 통일 (치환 · 기본 골격 · 대표 화합물 · 명명 과정 · 반응 메커니즘 · 후면 공격 · 안티-페리플래너 · 의사비대칭 등).
- 큰 분자: 구조식 겹침 풀기는 움직인 부분만 다시 세고, 입체중심 판정은 구조가 같으면 기억한 값을 씀 → 55원자에서 클릭 한 번 약 1초 → 0.03초. 분자 조립 뒤의 3D 분자는 가벼운 모드(H 없음 · 성긴 선 · 전환 · 커서 반응 없음 · 편집이 멈춘 뒤 한 번 · 30fps), ‘3D 보기’ 에서는 원래 모습.
- 렉 줄이기: 패널의 흐림(backdrop-filter)을 없앰 — 움직이는 3D 배경 위에서 매 프레임 다시 계산되어 가장 무거웠음. 프레임 시간을 보고 해상도를 자동으로 낮추고 올림, 움직임을 끄면 변화가 없을 때 다시 그리지 않음. 연달아 바뀌면 마지막 분자만 3D 로 만들고 짧게 전환, 같은 분자의 3D 좌표는 캐시, 다 맺힌 분자는 세 겹 대신 한 겹, 셰이더는 한 번만 컴파일, 비교 목록은 ‘비교’ 탭을 열었을 때만 잠깐 뒤에 채움.

## 이름 엔진 (`js/chem/`)
- `core.js` 원자 그래프, SMILES 읽기 · 쓰기(부분), 고리 · 방향족 판정, 분자식 · 몰질량
- `layout.js` 2D 좌표 (지그재그 사슬, 고리, E/Z 유지)
- `edit.js` 조각 붙이기 · 결합 바꾸기 · 가지 지우기 · E/Z 뒤집기 · 시작 분자
- `name.js` IUPAC 2013 권고 기준 일반 이름 엔진: 사슬 · 고리 · 벤젠 · 바이페닐 모체, 주 작용기 → 주사슬(길이 먼저) → 번호 → 알파벳 순 접두사(괄호 치환기 포함) → E/Z. 옛 규칙(이중결합 먼저)과 다르면 함께 알려 줌
- `cip.js` CIP 우선순위로 E/Z · 입체중심 판정 (처음 갈린 자리까지 알려 줌)
- `stereo.js` R/S: 원자의 배열(chi) + CIP 순위 → R 또는 S. 고리 cis/trans (고리 두 탄소의 치환기가 같은 면 · 반대 면): 1,4-이치환처럼 R/S 가 없으면 `trans-1,4-dimethylcyclohexane`, 있으면 상대 배치 이름 `trans-2-methylcyclohexan-1-ol` 도 함께. 이중결합은 양쪽에 H 가 하나씩일 때 `cis-but-2-ene`. 쐐기 고르기(헷갈리는 T자 그림 피함), 새 입체중심의 배열 정하기, 뒤집기 · 거울상, 풀이용 순위 근거. 가짜 비대칭 중심(소문자 r/s): 원자로는 같은 두 가지가 R · S 거울상이면 CIP 규칙 4 · 5 로 `(2R,3r,4S)-pentane-2,3,4-triol` · `(1R,2S,4s)-4-methylcyclopentane-1,2-diol` (RDKit 새 CIP 판정과 같음). 1,3,5-트라이메틸사이클로헥세인처럼 R/S · r/s 로도 나타나지 않는 고리 배치는 이름에 넣지 못했다고 알려 줌
- 이름: E/Z · R/S 를 번호 순서대로 한 괄호에 `(2R,3E)-pent-3-en-2-ol`, 곁가지 안의 입체는 곁가지에 `N-[(S)-1-phenylethyl]…`. 번호가 같으면 Z · R 에 작은 번호 (IUPAC 2013 P-31.1.4.3.4)
- `common.js` 관용명, 이치환 벤젠의 o-/m-/p- 이름
- `explain.js` 풀이 단계와 "무엇이 바뀌었나" 문장 (조사 자동)
- `geom3d.js` 3D 좌표 (입체중심의 배열을 지킴)

## 반응 엔진 (`js/chem/react.js`, `reactions.js`)
스미스 · 브루스 유기화학의 핵심 반응을 원자 그래프 위의 규칙으로 계산합니다.
- 치환 · 제거: 기질(1차 · 2차 · 3차 · 벤질) × 시약(친핵성 · 염기 세기 · 부피) × 용매로 SN1 · SN2 · E1 · E2 판정, 자이체프 / 호프만, 탄소 양이온 자리옮김(1,2-H · 1,2-메틸)
- 알켄 · 알카인 첨가: 마르코브니코프 / 반마르코브니코프, syn · anti, 오존 분해, 린들라 · Na/NH₃
- 카보닐 · 산 유도체: 환원 선택성(NaBH₄ vs LiAlH₄ · DIBAL), 그리냐르(산–염기 끄기 포함), 비티히, 첨가–제거, 비누화
- 방향족: 치환기의 활성화 · 방향 지시 합산, 입체 장애
- 라디칼 할로젠화: 1차 · 2차 · 3차 H 수 × 상대 반응성으로 비율 계산 (Cl₂ vs Br₂)
- C–C 결합: 알돌 · 클라이젠, 디엘스–알더(ortho/para 규칙), 스즈키 · 헥 · 소노가시라, 올레핀 복분해(고리 닫기 5~8원 고리)
- 입체: 서로 떨어진 이중결합 둘이 따로 반응하면 두 자리의 배치는 서로 무관 → 입체이성질체 혼합물로 표시. SN2 는 배열이 뒤집힘(월든 반전, 예 (R)-2-브로모뷰테인 → (S)-2-아이오도뷰테인), SN1 · HX 첨가는 라세미, Br₂ · 할로하이드린은 anti, OsO₄ · 수소붕소화 · 에폭시화 · H₂ 는 syn 으로 두 입체중심의 상대 배열을 계산해 메소 / 라세미를 구별 (trans-뷰트-2-엔 + Br₂ → 메소)
- E2 안티 평면: 사슬은 두 입체중심의 배열로 E/Z 하나만(RDKit 3D 로 따로 확인), 고리는 trans-다이축만 (멘틸 클로라이드 → 덜 치환된 알켄만, 네오멘틸 클로라이드 → 자이체프)
- 브루스에서 더한 반응: 에폭사이드 열기(산 → 치환 많은 쪽, 염기 · LiAlH₄ · 그리냐르 → 적은 쪽, 배열 반전), HI 에터 절단, 알코올 첨가, 시먼스–스미스, 사이아노하이드린, 아세탈, 바이어–빌리거(이동 적성), 길만 1,4-첨가, 산 가수분해, α-브로민화, 할로폼, LDA 동역학적 알킬화, 프리델–크래프츠 양이온 자리옮김, SNAr, 벤자인(cine 치환), 산드마이어 · 다이아조늄 치환
- 반응마다 최신 이해: 기체상 SN2 라운드어바웃(2008), 비고전적 2-노보닐 양이온 X선 구조(2013), 협동 SNAr(2018), 비티히의 옥사포스페테인 직접 경로, 크리기 중간체(2012), 엔도 규칙의 한계, 미츠노부 · 아펠, 그린 케미스트리, 광산화환원(2008), 클릭 화학(2022 노벨), 유도 진화 효소(2018 노벨), 비대칭 촉매(2001 · 2021 노벨) 등

- `dev/c3d.html`: 무작위 분자 입체중심 1,364개가 3D 좌표에서도 같은 배열인지
- `dev/interact.py`: 실제 조작 시험 (조립 · 결과 탭 · 버그 제보함 · 3D 확대 · 회전 · 반응 예측 전체 시약 클릭 · 퀴즈 · 커서 효과)
