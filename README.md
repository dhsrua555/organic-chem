# HEXA 유기화학

분자를 직접 조립하며 **어떤 물질이 되고 IUPAC 이름이 어떻게 바뀌는지**, 그리고 시약을 넣으면 **무엇이 생기는지** 한 단계씩 보여 주는 유기화학 공부 앱입니다.

- 사이트: https://dhsrua555.github.io/organic-chem/
- 디자인: 짙은 남색 + 전기 파랑, 육각형 기하. 와이어프레임 3D 분자가 바뀔 때 가로 줄무늬로 풀렸다 맺힙니다 (orano.group 인터랙티브 슬라이더의 분위기를 참고, 자산은 옮기지 않음).
- 커서 효과 (igloo.inc 의 반응하는 화면을 참고): 커서를 느리게 따라오는 육각 조준선, 누른 자리에서 퍼지는 육각 물결, 3D 분자의 원자가 커서를 피해 밀려나며 빛나고 원자 이름표가 뜸, 바닥 격자에 커서 빛 · 물결. 길게 누르면 분자가 분해도처럼 벌어짐. 움직임 줄이기 설정에서는 꺼짐.
- 분자를 빠르게 바꿔도 끊기지 않게: 연달아 바뀌면 마지막 분자만 3D 로 만들고 짧게 전환, 같은 분자의 3D 좌표는 다시 계산하지 않음, 다 맺힌 분자는 세 겹 대신 한 겹으로 그림, 셰이더는 한 번만 컴파일, 비교 목록은 잠깐 뒤에 채움.

## 이름 엔진 (`js/chem/`)
- `core.js` 원자 그래프, SMILES 읽기 · 쓰기(부분), 고리 · 방향족 판정, 분자식 · 몰질량
- `layout.js` 2D 좌표 (지그재그 사슬, 고리, E/Z 유지)
- `edit.js` 조각 붙이기 · 결합 바꾸기 · 가지 지우기 · E/Z 뒤집기 · 시작 분자
- `name.js` IUPAC 2013 권고 기준 일반 이름 엔진: 사슬 · 고리 · 벤젠 · 바이페닐 모체, 주 작용기 → 주사슬(길이 먼저) → 번호 → 알파벳 순 접두사(괄호 치환기 포함) → E/Z. 옛 규칙(이중결합 먼저)과 다르면 함께 알려 줌
- `cip.js` CIP 우선순위로 E/Z · 입체중심 판정 (처음 갈린 자리까지 알려 줌)
- `stereo.js` R/S: 원자의 배열(chi) + CIP 순위 → R 또는 S. 쐐기 고르기(헷갈리는 T자 그림 피함), 새 입체중심의 배열 정하기, 뒤집기 · 거울상, 풀이용 순위 근거
- 이름: E/Z · R/S 를 번호 순서대로 한 괄호에 `(2R,3E)-pent-3-en-2-ol`, 곁가지 안의 입체는 곁가지에 `N-[(S)-1-phenylethyl]…`. 번호가 같으면 Z · R 에 작은 번호 (IUPAC 2013 P-31.1.4.3.4)
- `common.js` 관용명, 이치환 벤젠의 o-/m-/p- 이름
- `explain.js` 풀이 단계와 "무엇이 바뀌었나" 문장 (조사 자동)
- `geom3d.js` 3D 좌표 (입체중심의 배열을 지킴)

## 반응 엔진 (`js/chem/react.js`, `reactions.js`)
스미스 유기화학의 핵심 반응을 원자 그래프 위의 규칙으로 계산합니다.
- 치환 · 제거: 기질(1차 · 2차 · 3차 · 벤질) × 시약(친핵성 · 염기 세기 · 부피) × 용매로 SN1 · SN2 · E1 · E2 판정, 자이체프 / 호프만, 탄소 양이온 자리옮김(1,2-H · 1,2-메틸)
- 알켄 · 알카인 첨가: 마르코브니코프 / 반마르코브니코프, syn · anti, 오존 분해, 린들라 · Na/NH₃
- 카보닐 · 산 유도체: 환원 선택성(NaBH₄ vs LiAlH₄ · DIBAL), 그리냐르(산–염기 끄기 포함), 비티히, 첨가–제거, 비누화
- 방향족: 치환기의 활성화 · 방향 지시 합산, 입체 장애
- 라디칼 할로젠화: 1차 · 2차 · 3차 H 수 × 상대 반응성으로 비율 계산 (Cl₂ vs Br₂)
- C–C 결합: 알돌 · 클라이젠, 디엘스–알더(ortho/para 규칙), 스즈키 · 헥 · 소노가시라, 올레핀 복분해(고리 닫기 5~8원 고리)
- 입체: SN2 는 배열이 뒤집힘(월든 반전, 예 (R)-2-브로모뷰테인 → (S)-2-아이오도뷰테인), SN1 · HX 첨가는 라세미, Br₂ · 할로하이드린은 anti, OsO₄ · 수소붕소화 · 에폭시화 · H₂ 는 syn 으로 두 입체중심의 상대 배열을 계산해 메소 / 라세미를 구별 (trans-뷰트-2-엔 + Br₂ → 메소)
- 교과서 이후: 2013 IUPAC 권고, 비고전적 2-노보닐 양이온 X선 구조(2013), 협동 SNAr(2018), 기체상 SN2 "라운드어바웃" 경로(2008), 비티히의 옥사포스페테인 직접 경로, 크리기 중간체 관찰(2012), 비대칭 · 광산화환원 · 효소 촉매 등

## 검증
- `dev/test.html`: 알려진 이름 235개, R/S 16개 포함 (Playwright 로 `python dev/run.py test.html` → `RESULT: ALL OK`)
- `dev/enum2.html` + `dev/validate.py`: 최대 45원자 무작위 분자 약 12,000개(절반은 입체중심마다 무작위 R/S, MOL 에 쐐기)의 이름을 OPSIN 으로 다시 구조로 풀어 RDKit 으로 원래 구조와 비교 → 전부 일치. R/S 는 RDKit 의 새 CIP 판정기와도 전부 같음 (`enum2.html?rs=1`)
- `dev/rtest.html`: 교과서 반응 103개의 주 · 부생성물, 입체 13개 포함 (`python dev/run.py rtest.html` → `RESULT: ALL OK`)
- `dev/c3d.html`: 무작위 분자 입체중심 1,364개가 3D 좌표에서도 같은 배열인지
- `dev/interact.py`: 실제 조작 시험 (조립 · 3D 확대 · 회전 · 반응 예측 전체 시약 클릭 · 퀴즈 · 커서 효과)
- `dev/pubchem.py`: PubChem IUPAC 이름과 표본 비교 (차이는 `ethan-1-one` · `acetic acid` 같은 표기 관례뿐)
