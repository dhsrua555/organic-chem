# HEXA 유기화학

벤젠 고리 · 프로펜 사슬 같은 뼈대의 H 자리에 작용기를 붙이며, **어떤 물질이 되고 IUPAC 이름이 어떻게 바뀌는지** 한 단계씩 보여 주는 유기화학 공부 앱입니다.

- 사이트: https://dhsrua555.github.io/organic-chem/
- 디자인: 짙은 남색 + 전기 파랑, 육각형 기하. 와이어프레임 3D 분자가 바뀔 때 가로 줄무늬로 풀렸다 맺힙니다 (orano.group 인터랙티브 슬라이더의 분위기를 참고, 자산은 옮기지 않음).

## 이름 엔진 (`js/chem/`)
- `mol.js` 뼈대 · 작용기 → 원자 그래프, 분자식 · 몰질량
- `name.js` IUPAC 2013 권고 기준 이름 (주 작용기 → 주사슬(길이 먼저) → 번호 → 알파벳 순 접두사 → E/Z). 옛 규칙(이중결합 먼저)과 다르면 함께 알려 줌
- `cip.js` CIP 우선순위로 E/Z · 입체중심 판정
- `common.js` 관용명, 이치환 벤젠의 o-/m-/p- 이름
- `explain.js` 풀이 단계와 "무엇이 바뀌었나" 문장 (조사 자동)
- `geom3d.js` 3D 좌표 (E/Z 유지)

## 검증
- `dev/test.html`: 알려진 이름 161개 (Playwright 로 `python dev/run.py test.html` → `RESULT: ALL OK`)
- `dev/enum.html` + `dev/validate.py`: 작용기 2개까지 전부와 3~4개 무작위, 약 37,600개 분자의 이름을 OPSIN 으로 다시 구조로 풀어 RDKit 으로 원래 구조와 비교 → 전부 일치, 같은 구조에 다른 이름 0
- `dev/pubchem.py`: PubChem IUPAC 이름과 표본 비교 (차이는 `ethan-1-one` · `acetic acid` 같은 표기 관례뿐)
